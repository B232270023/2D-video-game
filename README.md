\## Төслийн зорилго



Энэхүү төслийн зорилго нь Unity ашиглан 2D Tower Defense төрлийн тоглоом хөгжүүлж, тоглогч дайснуудын зам дагуу хамгаалалтын цамхагуудыг стратегийн байрлалд байршуулан дайснуудыг устгаж, сууриа хамгаалах боломжтой тоглоомын орчин бүрдүүлэхэд оршино.



Тоглоомд Archer болон Wizard зэрэг өөр өөр үүрэг, чадвартай хамгаалалтын цамхагуудыг ашиглан дайснуудыг довтлох бөгөөд цамхаг бүр өөрийн довтлох хүрээ, damage, attack speed болон cooldown-той байна. Мөн дайсан устгахад тоглогч gold авч, тоглоомын явцад хамгаалалтаа сайжруулах боломжтой байхаар төлөвлөж байна.



Төслийн хүрээнд Unity-ийн 2D Tilemap, C# скрипт, tower placement, enemy movement, targeting, projectile болон game management зэрэг үндсэн системүүдийг ашиглан тоглох боломжтой Tower Defense тоглоом бүтээнэ.
